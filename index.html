第一章

AI 时代，会说话就会编程

🎮 初体验：用 AI 做贪吃蛇游戏

让我们通过一个简单的贪吃蛇游戏，感受 AI 编程的魅力。你只需要对 AI 说：

提示词示例：
"帮我创建一个贪吃蛇游戏，使用 HTML5 Canvas。要求：
  • 蛇身用绿色方块表示，食物用红色圆形
  • 支持键盘方向键控制
  • 有得分系统和游戏结束判定
  • 界面简洁美观，有开始和重新开始按钮"

💡 核心概念：什么是 Vibe Coding？

Vibe Coding（氛围编程）是一种新兴的编程范式，核心思想是：

  • 自然语言编程：用日常语言描述需求，而非编程语法
  • AI 辅助实现：AI 负责代码生成，你负责产品思维
  • 快速验证：先做出能用的东西，再逐步优化
  • 迭代开发：持续与 AI 对话，不断完善产品

第二章

寻找好想法与产品验证

🎯 如何找到值得做的项目？

好的项目想法通常来自以下三个来源：

😤

你自己或身边人经常遇到的烦恼

💡
灵感启发

看到某个产品，想到更好的做法

🎨
兴趣驱动

结合你的爱好和专业领域

✅ 验证想法：The Mom Test

不要问"你觉得这个想法好吗？"，而要问：

  • "你上次遇到这个问题是什么时候？"
  • "你现在是怎么解决这个问题的？"
  • "如果解决这个问题，对你有什么帮助？"
⚠️ 常见错误：不要陷入"解决方案寻找问题"的陷阱。先确认问题真实存在，再考虑解决方案。
第三章

动手做出原型

📝 从需求到代码的提示词工程

写好提示词是 Vibe Coding 的核心技能。一个好的提示词应该包含：

提示词模板（PRD 模式）
【产品名称】：极简待办清单
【目标用户】：需要管理日常任务的上班族
【核心功能】：
1. 添加、完成、删除待办事项
2. 按优先级排序（高/中/低）
3. 本地存储，刷新不丢失
【界面要求】：
- 简洁清新的设计风格
- 支持深色模式
- 移动端适配
【技术栈】：HTML + Tailwind CSS + JavaScript

后端 后端与数据库

🗄️ Supabase 数据库

Supabase 是开源的 Firebase 替代品，提供 PostgreSQL 数据库、实时订阅、认证等功能。

-- 创建表示例
CREATE TABLE todos (
  id SERIAL PRIMARY KEY,
  title TEXT NOT NULL,
  completed BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 启用行级安全（RLS）
ALTER TABLE todos ENABLE ROW LEVEL SECURITY;
